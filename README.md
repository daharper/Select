# Select

- C# 12
- .NET Framework 4.8.1
- WinForms

Simple application to help practice SELECT statements using an MSAccess Northwind database.

In the Web Helper, there are a set of exercises that can be executed against the database:

- Northwind Questions Part 1
- Northwind Questions Part 2

There are accompanying answers available in the same menu.

You should be able to download or clone the project, open it in Rider or VS 2022, and run it.
